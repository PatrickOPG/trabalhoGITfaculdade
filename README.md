Sistema Escolar — Gerência de Configuração de Software

📌 Sobre o Projeto

Este projeto foi desenvolvido como atividade acadêmica da disciplina de Gerência de Configuração de Software (GCS), com o objetivo de aplicar conceitos de controle de versão e desenvolvimento colaborativo utilizando Git e GitHub.

O projeto utiliza Java e Maven e tem como proposta trabalhar a organização do código, o controle de alterações e a colaboração entre os integrantes da equipe.

🎯 Objetivos

Aplicar conceitos de Gerência de Configuração de Software.

Utilizar Git e GitHub para controlar versões do projeto.

Organizar o desenvolvimento por meio de branches.

Registrar alterações utilizando commits.

Praticar a integração de código e a resolução de conflitos.

Desenvolver habilidades de trabalho em equipe.

🛠️ Tecnologias Utilizadas

Java: linguagem de programação utilizada no projeto.

Maven: ferramenta para gerenciamento de dependências e configuração da aplicação.

Git: sistema de controle de versões.

GitHub: plataforma para hospedagem do repositório e colaboração.
